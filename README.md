# 💖 推し活チェキ帳 [Cheki Book]

推しメンとの大切な思い出（チェキ・写メ）やイベントの記録を、可愛くスマートに管理・振り返ることができるWebアプリケーションです。

🌐 **Webアプリはこちら:** [https://chuenli2006.github.io/oshi-cheki/](https://chuenli2006.github.io/oshi-cheki/)

---

## ✨ 主な機能

*   **💭 ホーム画面（思い出バブル）**
    *   登録した画像付きチェキ・写メが、画面上をフワフワとランダムに浮かび上がります。
    *   流れてくるチェキをタップすると、**3Dフリップアニメーション**でクルッと裏返り、当時のメモや裏書きを楽しむことができます。
*   **📸 マイチェキ帳（グループ＆カテゴリ別管理）**
    *   グループ名や店舗名ごとに推しメンが美しく階層化されます。
    *   「アイドル」「コンカフェ」などのカテゴリ小バッジ付きで、推しのジャンルが一目で分かります。
    *   チェキ（📷）と写メ（📱）のタブ切り替えギャラリーに対応。
*   **✨ かんたん記録追加 ＆ Imgur自動アップロード**
    *   既存メンバーのサジェスト機能付きで、名前入力の手間を軽減。
    *   画像ファイルを選択するだけで、自動でImgurに匿名アップロード＆URLが反映されます。
*   **🎨 10種類のカラーテーマ着せ替え**
    *   「ぴんく」「だーく」「ブラック」「ネオン」「ゴールド」など、推しのイメージや気分に合わせてアプリ全体の色合いを自由に変更できます。
*   **📤 バックアップ ＆ 友達との共有**
    *   JSONファイルによるデータの全バックアップ・復元はもちろん、推しメン単位でのデータ共有にも対応しています。

## 🛠 導入・使い方

1. サイト（[https://chuenli2006.github.io/oshi-cheki/](https://chuenli2006.github.io/oshi-cheki/)）にアクセスします。
2. 画面右上の **👤 ユーザー名** から自分の名前を設定します。
3. 右下の **「＋」ボタン** から、年・月・推しメン名・画像などを入力して記録を追加！
4. ホーム画面やギャラリーで、これまでの思い出をいつでも振り返りましょう✨
